## 住宅 IP、原生 IP、双 ISP 是三件事，别被名字绕进去

这三个词经常被混着用，实际指向完全不同：

**住宅 IP** 指 IP 注册在真实民用宽带运营商名下，比如 AT&T、Comcast、T-Mobile、Astound、RCN、Frontier，IP 数据库把它标记为 residential，平台更倾向当作普通家庭用户。

**原生 IP** 指 IP 的注册地与实际使用地一致。注册在美国、也在美国落地，就是美国原生 IP。原生只说明归属地匹配，不说明这个 IP 来自家庭宽带还是数据中心。

**双 ISP** 指 IP 同时注册在两个运营商名下，用来强化家宽属性。SixtyNet 的住宅系列就分单 ISP 和双 ISP 两档。

行业里有种常见的命名陷阱：把便宜档标成“非原生 IP”，想要真原生得加钱换。买之前一定要看清套餐名旁边的小字，别只看价格。

副标题里那句“怎么自己验 IP”，具体是三步：

1. 通过这台机器的代理访问 `ipinfo.io/json`，看 `org` 字段。显示 AS7018 AT&T Services、AS7922 Comcast Cable 这类个人用户 ISP 偏住宅；显示 DigitalOcean、AWS、Azure 就是数据中心。
2. 看 `hosting` 和 `type` 字段。`hosting` 为 true 是强数据中心信号，`type` 为 isp 偏住宅、为 hosting 偏机房。
3. 用 Scamalytics 查风险分和 is_datacenter 标记，再拿目标平台（TikTok、Netflix、ChatGPT）实际登录测试解锁情况。

有个前提得说清楚：`type` 字段描述的是拥有 ASN 的组织类型，不保证每一个 IP。同一家公司的网络里可能同时有家庭宽带和商业线路。任何单一指标都无法 100% 证明住宅属性，得把 ASN 归属、地理位置、平台实测三项合起来看。

第三方测评对 SixtyNet 这台机器的判断是：ipinfo 显示双 ISP 属性，多个数据库判定为美国原生 IP、家宽属性、纯净无风险，流媒体解锁全绿。这是 2025 年 10 月的测试结果，IP 段会变，你拿到手还是要自己跑一遍上面三步。

路由方面，测评记录的是电信去程 CN2 直连洛杉矶，联通去程直连后接 GTT 再接 Cox，移动直连；回程电信和移动走 CN2，联通走 AS10099 + AS9929。对国内访问有优化，但官方屏蔽 ping，实际延迟只能自己测。
